化学常用公式速查

物质的量

n = m/M = V/Vm = N/NA

c = n/V | c₁V₁ = c₂V₂

热化学

ΔH = ΣE(断键) - ΣE(成键)

盖斯定律：ΔH = ΔH₁ + ΔH₂ + ...

化学平衡

K = [C]ᶜ[D]ᵈ / [A]ᵃ[B]ᵇ

转化率 = Δn/n₀ × 100%

pH 计算

pH = -lg[H⁺]

pH + pOH = 14 (25°C)

电化学

Q = It = n(e⁻)F

F = 96,500 C/mol

气体定律

PV = nRT

M = ρRT/P (理想气体)
